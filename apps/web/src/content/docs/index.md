Welcome to the BulletinMail docs. They're organized by the [Diataxis](https://diataxis.fr/) framework:

- **[Explanation](/docs/explanation/)** — the why. Architecture, domain strategy, distribution model.

Use the sidebar to navigate, or the search box (⌘K) for a specific term.

If you want to run BulletinMail under your own brand, the [Self-hosting guide](/docs/how-to/self-host/) is the place to begin.
